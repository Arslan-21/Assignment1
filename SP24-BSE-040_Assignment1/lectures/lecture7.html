Responsive Web Design

Make one page work on phones, tablets and desktops.

Summary

Explains the viewport meta tag, fluid widths, flexible images and media queries, and why designing mobile first keeps CSS simple.

Topics covered

  • Foundations
    • Viewport meta tag
    • Fluid layouts
  • Media Queries
    • Breakpoints
    • min-width and max-width
  • Flexible Media
    • max-width: 100% images
    • Responsive units

Example code

@media (max-width: 600px) {
  .menu { flex-direction: column; }
}

Output

On screens 600px wide or less, the menu stacks vertically.
