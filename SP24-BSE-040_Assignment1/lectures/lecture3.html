HTML Forms and Media

Collect user input and embed audio, video and images.

Summary

Explains form controls, labels and submission, basic validation attributes, and the audio, video and figure elements.

Topics covered

  • Forms

    • Input types
    • Labels and buttons
  • Validation
    • required and pattern
    • min and max
  • Media
    • img and figure
    • audio and video

Example code

  <label>Email <input type="email" required></label>
  <button>Send</button>
</form>
